# consulting-html-ppt — 諮詢級交付簡報

> 方法論來源：`sharptoolbox/consulting-html-ppt`（原 repo 未宣告開源授權）。本檔為**方法論要點的獨立重述**，未複製其模板庫、圖標、成品或規範全文。原始連結：https://github.com/sharptoolbox/consulting-html-ppt 。說明見同目錄 `ATTRIBUTION.md`。

## 何時使用

需要把交付成果、技術方案、審查報告做成**可直接放映的單檔 HTML 簡報**時：階段驗收彙報、架構方案評審、經營分析、產品講解。由交付簡報設計師（delivery-designer）主導。

不適用：純文字摘要（直接回覆即可）、需要真實影片配音（走外部工具）。

## 核心方法

### 四形態判定（按優先級，不得跳步）
| 順序 | 頁面內容 | 版式 |
|------|----------|------|
| 1 | 有數值序列／對比／占比／歸因 | **數據頁**：真實圖表，禁止用示意 SVG 冒充 |
| 2 | 軟體／IT 系統的構成、運行、演進 | **架構圖頁**：分層、應用、數據、微服務、部署、演進等 |
| 3 | 有結構關係但無數值（層級／流程／因果／矩陣／閉環） | **圖形頁**：結構模型 |
| 4 | 只剩並列類目 | **文本分類頁**：「線＋框」骨架，禁止純段落與圓點 bullet |

一頁只講一件事，標題必須是**動作式結論**（不是「架構圖」這種圖名）。

### 硬骨架（1920×1080）
- 純白背景 `#FFFFFF`、Flat Design（無漸變／陰影／發光／3D）
- 四邊 20px 邊界；標題區 y 20–170，標題 48px 加粗；y=170 處 5px 純黑分隔線拉通全寬
- 內容區 y 175–1060；分欄時左 700px 文字、右 1120px 圖形
- 單一 HTML 檔、鍵盤翻頁、圓點跳轉、居中縮放

### 模板化紀律
圖形骨架必須來自統一的模板庫、只替換文字與數值；骨架、配色語義、線宽不得自創。原項目的模板庫受其作者權利影響，**本 Skill 不附帶模板**——使用時應以 WorkBuddy 內建模控規則或自行設計的模板替代，不要複製原 repo 資產。

### 質檢
逐頁對照：標題是否為結論、形態判定是否正確、圖是否居中、是否只有一處強調色、是否有 Oxford 式留白、數值是否真實。不合格即返工。

## 與團隊協作

交付簡報設計師負責 Phase 6「交付敘事」；輸入為主理人彙編的交付摘要、阿奇的架構圖（可搭配 `visual-model`）、維拉的驗證報告。所有技術結論必須可追溯到源碼或測試證據，不得為美觀虛構數據。
